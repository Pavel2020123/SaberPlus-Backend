# Panel administrativo de SaberPlus

Esta carpeta alojara el panel web privado para gestionar areas, temas,
subtemas, lecciones, casos, preguntas y recursos. Su implementacion corresponde
a la etapa 7F-C3.

El panel utilizara la API NestJS y no tendra acceso directo a las credenciales
ni a las tablas de Supabase.
